> 👉 **The modern Windows version of GnollHack replaces the legacy Windows version. It adds the following features:**

- Modern UI based on the mobile ports of the game.
- Icons for all the commands in the game.
- Animated damage texts when hitting monsters and similar effects.
- Configurable quick actions for the right and middle mouse buttons (see [[Desktop Features]]).
- Game controller support for Xbox and other XInput controllers (see [[Steam Deck Controls]]).
- Breathing animations.
- [[GnollHack Account]] integration.
- Support for replays.

Each version has its own page: [[Modern Windows Version]] and [[Legacy Windows Version]].
