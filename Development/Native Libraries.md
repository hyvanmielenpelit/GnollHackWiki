## All Platforms

- GnollHack C Library: the core game engine
- [FMOD](https://www.fmod.com/): audio engine for sound effects and music
- [SkiaSharp](https://github.com/mono/SkiaSharp): 2D rendering engine for tile maps and UI. See also [[/Development/SkiaSharp Build Instructions]].
  
## Windows (Modern)

- [ANGLE](https://chromium.googlesource.com/angle/angle): translates OpenGL ES calls to Direct3D for SkiaSharp GPU rendering on Windows
