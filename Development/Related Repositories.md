> 👉 **This page lists the official GitHub repositories related to GnollHack development.**

| Repository | Type | Description |
| :--------- | :--- | :---------- |
| [GnollHack](https://github.com/hyvanmielenpelit/GnollHack) | Main repository | Game source files |
| [GnollHack Tile Set](https://github.com/hyvanmielenpelit/GnollHackTileSet) | Asset repository | Tile graphics source files |
| [GnollHack Sound Set](https://github.com/hyvanmielenpelit/GnollHackSoundSet) | Asset repository | Sound, music, and voiceover source files |
| [Tile Set Compiler](https://github.com/hyvanmielenpelit/TileSetCompiler) | Asset building tool | Used to compile tile graphics into sprite sheets |
| [GnollHack Account (aka MobileGnollHackLogger)](https://github.com/hyvanmielenpelit/MobileGnollHackLogger) | Server software | Records finished games, among other things, and holds the Gnoll Overseer and GnollBench |
| [GnollHack Wiki](https://github.com/hyvanmielenpelit/GnollHackWiki) | Documentation | Source files for GnollHack wiki running on [Gollum wiki software](https://github.com/gollum/gollum/) |
| [GnollHack Wiki Config](https://github.com/hyvanmielenpelit/GnollHackWikiConfig) | Documentation | Configuration of the Gollum wiki software for the GnollHack wiki |
| [GnollHack.com Website](https://github.com/hyvanmielenpelit/GnollHackMarketingWebsite) | Website | Source code of the gnollhack.com website |
| [Overseer Knowledge Base](https://github.com/hyvanmielenpelit/OverseerKnowledgeBase) | Documentation | Articles that the Gnoll Overseer reads about the GnollHack app |
