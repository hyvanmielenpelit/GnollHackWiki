## Windows, Linux and macOS

When using the Windows, Linux or macOS version, you need to enable **Save File Tracking** in the settings before you can enable **Server Posting**. Save File Tracking tracks that:

1. Your saved games are loaded only once.
2. Your save files are not modified.

This should make *save scumming* impossible.

## Android and iOS

On Android and iOS phones and tablets, enabling **Save File Tracking** does nothing at the moment. When the mobile version runs on a desktop computer, such as the iOS version on a Mac, it works as on the desktop versions.
