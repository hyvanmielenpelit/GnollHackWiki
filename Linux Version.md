## 1. Download Options

GnollHack's Linux version has the following download options:

- **Steam** — Recommended download option (also covers the Steam Deck).
- **AppImage** — A single self-contained file available on GitHub that you can use without Steam.

### 1.1. Steam

<a href="https://store.steampowered.com/app/3558190/GnollHack/?utm_source=wiki">![Available on Steam](/uploads/Download/steam-q90.webp)</a><br />

#### 1.1.1. Auto-Update Can't Be Disabled

You can't disable auto-update in Steam, but if your saved games become invalid, you can revert to a compatible version of GnollHack as follows:

1. [[Contact the GnollHack Dev Team|Contact Information]] and ask that the previous game version will be made available. They will give you a code.
2. Go to GnollHack Properties in Steam.
3. Go to the Game Versions & Betas tab.
4. Enter the code to Private Versions and click Check Code.
5. The requested game version should become available for choosing.

#### 1.1.2. Steam Platform Features

- **Revert to Old Version** — You can revert to an old version using the Game Versions & Betas tab in the GnollHack properties in Steam *(see above)*.

### 1.2. AppImage

<a href="https://github.com/hyvanmielenpelit/GnollHack/releases">![Get release on GitHub](/uploads/Download/github-q90.webp)</a><br />

- The AppImage package has the **.AppImage extension**.
- It is a single self-contained file that runs on most 64-bit (x86-64) Linux distributions without installation or administrator rights.
- Install and run the game using these instructions: [[Installing the AppImage on Linux]]
- The AppImage version of the game *doesn't* have built-in auto-update. You update it manually by downloading a newer version (or using an AppImage updater).

## 2. System Requirements

- A 64-bit (x86-64) Linux desktop with a working graphics driver (Mesa for AMD and Intel, or NVIDIA's driver). X11 and Wayland desktops both work.
- Sound through PulseAudio or PipeWire, which most desktops use.
- In-game web pages, such as this wiki and [[Gnoll Overseer]], use the Chromium engine built into the game, so no web browser components need to be installed.

## 3. Recommended GnollHack Graphics Settings

- **GPU Acceleration:** On
- **Map FPS:** 60
- **Screen Resolution:** Recommended (Default) — _Maximum Resolution @ Maximum Refresh Rate_
- **Screen Scale:** Default
- **Platform Render Loop:** On

### 3.1. Notes

- Screen resolution and refresh rate can only be adjusted in the full-screen mode.
