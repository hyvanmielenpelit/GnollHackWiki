> 👉 **Looking for a graphical way to play NetHack? This page lists graphical NetHack ports and variants that have working, ready-to-play builds and have been updated within the last two years, grouped by whether you install them or play them in a web browser.**

## 📖 About This List

Every entry runs on the NetHack code base, shows the game with graphics such as tiles, isometric views, or 3D, has a build you can install or play without compiling anything, and has been updated since November 2024. Text-only builds, source-only projects, ports that have been superseded by a newer one, and games that are merely inspired by NetHack are left out; projects that were checked but dropped are listed in [[Unmaintained and Not Listed|#unmaintained-and-not-listed]].

Entries are in alphabetical order within each section. A project that has both an installable version and a browser version has an entry in each section. Store listings, prices, and download links change over time.

**Last web scan:** November 7, 2026. Each scan rechecks every entry on this page and searches the web, including the r/nethack subreddit, for new projects.

## 💾 Install on Your Device

### BlissHack

🧪 **Experiment** · Free · 🔇

A newcomer-friendly version of vanilla NetHack 5.0, with the official tiles by default, an ASCII mode, a graphical status display, and a customizable action bar. In alpha.

- [GitHub](https://github.com/lightmain/BlissHack/releases): Windows, macOS (Apple silicon)

### DartHack

🧪 **Experiment** · Free, with ads · 🔇

A touch-optimized Android port of vanilla NetHack 5.0 with a customizable virtual gamepad, support for custom tile sets, and English and Japanese text.

- [Google Play](https://play.google.com/store/apps/details?id=jp.satokiyo.darthack): Android

### EvilHack

🟢 **In active development** · Free · 🔇

A challenging NetHack 3.6 variant. The Windows download includes a graphical version with tiles, and a custom tile set is offered alongside it.

- [GitHub](https://github.com/k21971/EvilHack/releases): Windows

### GnollHack

⭐ 🟢 **In active development** · Free · 🎵

A NetHack variant with an animated, high-resolution 2D interface, voice acting, and support for touch, mouse, keyboard, and game controllers.

- [Steam](https://store.steampowered.com/app/3558190/GnollHack/?utm_source=wiki): Windows, macOS, Linux, Steam Deck
- [Google Play](https://play.google.com/store/apps/details?id=com.soundmindentertainment.gnollhack): Android
- [App Store](https://apps.apple.com/app/gnollhack/id1626979951): iPhone, iPad, Mac
- [GitHub](https://github.com/hyvanmielenpelit/GnollHack/releases): Windows, macOS, Linux, with builds that do not need a store: an MSIX installer and a legacy version for Windows, and an AppImage and an archive for Linux

### iNethack2

🟡 Maintained · Free · 🔇

An iOS port of vanilla NetHack 3.6.7 with several tile sets and an ASCII mode. Last updated in March 2025.

- [App Store](https://apps.apple.com/app/inethack2/id962114968): iPhone, iPad, Apple silicon Mac

### NetHack 3D

⭐ 🟢 **In active development** · Free · 🔇

A 3D interface for vanilla NetHack 5.0, NetHack 3.6.7, and SLASH'EM, with overhead, first-person, and virtual reality views, several built-in tile sets, and sound effects but no music.

- [GitHub](https://github.com/JamesIV4/nethack-3d/releases): Windows, macOS, Linux (including the Steam Deck), Android, Meta Quest

### NetHack 5.0 (official)

🟢 **In active development** · Free · 🔇

The NetHack DevTeam's current release, published in May 2026. The Windows download includes both a text version and a graphical version with tiles, which plays a few sound cues but no music. An MS-DOS build with an optional tiled display is also available.

- [nethack.org](https://www.nethack.org/v500/ports/download-win.html): Windows (x64 and ARM64)
- [nethack.org](https://www.nethack.org/v500/ports/download-msdos.html): MS-DOS

### NetHack Android

🟢 **In active development** · Free · 🔇

A NetHack 5.0 update of the long-standing Android port of vanilla NetHack, with tile graphics. Distributed as APK files.

- [GitHub](https://github.com/JodiJodington/NetHack-Android/releases): Android

### NetHack Cocoa

🟢 **In active development** · Free · 🔇

A native Mac app for vanilla NetHack 5.0, with a painted tile set in 64- and 128-pixel sizes and the classic tiles.

- [GitHub](https://github.com/glorat/nethack-cocoa/releases): macOS 12 or later

### NetHack Tiles Client

🧪 **Experiment** · Free · 🔇

A desktop client that connects to the NAO and Hardfought public servers and draws the game with tiles instead of text.

- [GitHub](https://github.com/statico/nethack-tiles-client/releases): Windows, macOS, Linux

### NetHackJP

🧪 **Experiment** · Free · 🔇

An unofficial Japanese translation of NetHack 5.0, with a graphical interface on Windows and Qt and X11 interfaces on Linux.

- [GitHub](https://github.com/satokiyon/NetHackJP/releases): Windows, Linux

### VoxHack

🧪 **Experiment** · Pay what you want on itch.io, free on GitHub · 🎵

NetHack 3.7 in a first-person 3D voxel world, built on the Luanti engine. In early alpha, with frequent new builds.

- [itch.io](https://mreveryday.itch.io/voxhack): Windows
- [GitHub](https://github.com/MrEveryDay98/VoxHack/releases): Windows, with every build available as a free download

### xNetHack

🟢 **In active development** · Free · 🔇

A NetHack variant that refines and expands the vanilla game. The Windows download includes a graphical version with tiles.

- [GitHub](https://github.com/copperwater/xNetHack/releases): Windows

### ZeldHack for NetHack

🟡 Maintained · Free · 🎵

A ready-to-play Windows package of vanilla NetHack 3.6.7 with music, sound effects, and a 32×32 tile set inspired by the first Zelda game. It needs no setup beyond unzipping it.

- [itch.io](https://lspixel.itch.io/zeldhack-for-nethack-ready-to-play): Windows

## 🌍 Play in a Web Browser

### BlissHack (web version)

🧪 **Experiment** · Free · 🔇

The browser version of [[BlissHack|#blisshack]]. It plays vanilla NetHack 5.0 with tiles, and there is nothing to install.

- [BlissHack](https://lightmain.github.io/BlissHack/): Web browsers

### Hardfought web terminal

🟢 **In active development** · Free · 🔇

Browser play on the Hardfought public servers in North America, Europe, and Australia. Tiles are available for several variants, including xNetHack, EvilHack, SpliceHack, and UnNetHack, when `OPTIONS=vt_tiledata` is set in the options file. Requires a free account.

- [Hardfought](https://www.hardfought.org/hterm/): Web browsers

### NAO web terminal

🟢 **In active development** · Free · 🔇

Browser play on the nethack.alt.org (NAO) public server, with vanilla NetHack 5.0 and 3.6 and a choice of tile sets. Requires a free account.

- [NAO](https://alt.org/nethack/hterm/): Web browsers

### NetHack 3D (web version)

⭐ 🟢 **In active development** · Free · 🔇

The browser version of [[NetHack 3D|#nethack-3d]]. It plays vanilla NetHack 5.0, NetHack 3.6.7, or SLASH'EM in 3D without installing anything.

- [NetHack 3D](https://jamesiv4.github.io/nethack-3d/): Web browsers, including mobile

### NetHack Browser Edition

🟡 Maintained · Free · 🔇

Vanilla NetHack 3.6.7 in the web browser, with several tile sets, a text mode, and optional cloud saves. It has a few sound effects but no music.

- [roguelike.run](https://roguelike.run/): Desktop and mobile web browsers

### nethack.app

🧪 **Experiment** · Free · 🔇

An unofficial web port of vanilla NetHack 5.0 with the layout of NetHack Cocoa and a choice of painted 64-pixel tiles, the classic tiles, or ASCII. It works offline once loaded, and an online mode, in beta, keeps your games available across devices and adds them to public high scores.

- [nethack.app](https://nethack.app/offline/): Web browsers

### VectHack

🧪 **Experiment** · Free · 🔇

Vanilla NetHack 5.0 in the web browser, drawn as glowing arcade vector graphics: monsters are rotating letterforms and dungeons are wireframe geometry, seen through an orbital or a first-person camera. The same site also plays Angband, Larn, and Moria.

- [vecthack.net](https://vecthack.net/): Web browsers

### WebHack

🧪 **Experiment** · Free · 🔇

A browser interface for vanilla NetHack 5.0 that reinterprets the classic ASCII art in first-person 3D. The games run on its own server, which keeps a global high score ladder. In open beta.

- [webhackgame.com](https://webhackgame.com/): Web browsers

## 🎖️ Scoreboards and Tournaments

The [NetHack Scoreboard](https://nethackscoreboard.org/) is the NetHack community's leaderboard across servers and variants, and [[Junethack]] is the community's cross-variant tournament, held every June. Both read the game logs of a fixed list of servers, such as the NAO and Hardfought public servers, so a game you play on your own device counts only if the port reports it to one of those servers. These projects on this page have their games counted by both:

- **GnollHack:** Every build except the [[Legacy Windows Version]] can post finished games to the [[GnollHack Account]] server, which both sites track. The NetHack Scoreboard needs [[Classic Mode]] and [[/Difficulties/Expert]] difficulty or higher. For Junethack, link your Junethack username to your GnollHack Account and turn on [[Tournament Mode]]. GnollHack games on the Hardfought servers are counted as well.
- **Hardfought web terminal:** Games on all three Hardfought servers, including the variants with tiles, such as xNetHack, EvilHack, SpliceHack, and UnNetHack.
- **NAO web terminal:** The NetHack Scoreboard counts both NetHack 5.0 and 3.6 games; Junethack 2026 counted only NetHack 5.0.
- **NetHack Tiles Client:** The games run on the NAO and Hardfought servers, so they count the same as games in their web terminals.

The other projects on this page, including NetHack 3D, VoxHack, DartHack, and the official NetHack 5.0 download, keep their games on your own device, and neither site counts them. WebHack and the online mode of nethack.app keep their games on their own servers, with high score lists that the NetHack Scoreboard does not read. EvilHack and xNetHack games count only when played on Hardfought, not in their Windows downloads.

## 🏆 Most Developed Interfaces

Judged only by the work put into the graphical interface itself, not by gameplay changes, server hosting, or other development, these projects stand out:

- **GnollHack** — Over 23,000 hand-drawn animated tiles, 37 music tracks, over 1,100 sound effects, and over 5,000 voiced lines, in a custom interface built for touch, mouse, keyboard, and game controllers. The interface has been developed since 2019 and runs on Android, iOS, Linux, macOS, Windows, and the Steam Deck.
- **NetHack 3D** — A full 3D renderer with overhead, first-person, and virtual reality views, several built-in tile sets, and sound effects, developed since 2025. It runs in web browsers and on Android, Linux, macOS, Windows, and Meta Quest, and has frequent releases.
