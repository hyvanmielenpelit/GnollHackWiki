> 👉 **You can play NetHack and several of its variants with graphics without compiling anything, from an online store, a download page, or a web browser.**

## 📖 About This List

Every entry runs on the NetHack code base, shows the game with graphics such as tiles, isometric views, or 3D, has a build you can install or play without compiling anything, and has been updated since November 2024. Text-only builds, source-only projects, ports that have been superseded by a newer one, and games that are merely inspired by NetHack are left out; projects that were checked but dropped are listed in [[Unmaintained and Not Listed|#unmaintained-and-not-listed]].

Entries are in alphabetical order within each section. A project with a listing in an online store is under Online Stores, together with its other downloads. A project that has both an installable version and a browser version has an entry in each section.

In the platform lists, macOS means a native Mac app. Apple silicon Mac means an iPhone and iPad app from the App Store, which Macs with Apple silicon can also run, and the 📱 icon marks a project that runs on a Mac only this way. For a browser version, desktop web browsers means that it is played with a keyboard or mouse, and mobile web browsers means that it can also be played by touch on a phone or tablet.

## 🌍 Play in a Web Browser

> ⚠️ **Warning:** Most of these ports keep your saved games only in the browser's own storage on your device. Safari, on iPhone, iPad, and Mac, deletes everything a site has stored after seven days of Safari use without you playing on that site, saved games included. A site added to the Home Screen on iPhone or iPad, or to the Dock on a Mac, and opened from there is exempt, but it does not see the saves made in a Safari tab. Other iPhone and iPad browsers use Safari's engine and may delete data the same way. In any browser, clearing the site's data deletes the saves, so export them where the port allows it. The Hardfought and NAO web terminals and WebHack keep games on their servers and are not affected.

### BlissHack (web version)

🧪 **Experiment** · Free · 🔇 · ⚠️

The browser version of [[BlissHack|#blisshack]]. It plays vanilla NetHack 5.0 ✅ with tiles, and there is nothing to install. On a phone, you move by tapping the map and give commands from its action bar. Saves are kept in the browser, and a save can be exported to a file and imported again.

- [BlissHack](https://lightmain.github.io/BlissHack/): Desktop and mobile web browsers

### Hardfought web terminal

🟢 **In active development** · Free · 🔇 · 🖥️

Browser play on the Hardfought public servers in North America, Europe, and Australia, with vanilla NetHack 5.0 ✅ and many variants. Tile sets are offered for vanilla NetHack 5.0 and for EvilHack, SpliceHack, TNNT, UnNetHack, and xNetHack, when `OPTIONS=vt_tiledata` is set in the options file. The servers also host the older vanilla versions 3.6 and 3.4.3 and other variants, such as GnollHack, but the web terminal shows them as text only. It is a terminal played with a keyboard, with no touch controls. Requires a free account.

- [Hardfought](https://www.hardfought.org/hterm/): Desktop web browsers

### NAO web terminal

🟢 **In active development** · Free · 🔇 · 🖥️

Browser play on the nethack.alt.org (NAO) public server, with vanilla NetHack 5.0 ✅ and 3.6 🕰️ and a choice of tile sets. It is a terminal played with a keyboard, with no touch controls. Requires a free account.

- [NAO](https://alt.org/nethack/hterm/): Desktop web browsers

### neohack

🧪 **Experiment** · Free · 🔇 · ⌨️ ⚠️

Vanilla NetHack 5.0 ✅ in the web browser, drawn with animated pixel-art sprites, with a switch to classic NetHack symbols and touch controls for phones, which include an on-screen keypad for moving. It adds a few helpers that vanilla NetHack does not have, such as auto-explore and clicking a square to walk there, and AI agents and player-written bots can play it too. It can be installed as a web app for offline play. Saves are kept in the browser, and the game can also keep a copy on its server. In alpha.

- [neohack.dev](https://neohack.dev/): Desktop and mobile web browsers

### NetHack 3D (web version)

⭐ 🟢 **In active development** · Free · 🔇 · ⚠️

The browser version of [[NetHack 3D|#nethack-3d]]. It plays vanilla NetHack 5.0 ✅, NetHack 3.6.7 🕰️, or SLASH'EM in 3D without installing anything. On a phone or tablet, you move by tapping or swiping the map and give commands from a bar of buttons and an action menu. - [NetHack 3D](https://jamesiv4.github.io/nethack-3d/): Desktop and mobile web browsers

### NetHack Browser Edition

🟡 Maintained · Free · 🔇 · ⚠️

Vanilla NetHack 3.6.7 🕰️ in the web browser, with several tile sets and a text mode. It has a few sound effects but no music. ### nethack.app

🧪 **Experiment** · Free · 🔇 · ⚠️

## 🎖️ Scoreboards and Tournaments

The [NetHack Scoreboard](https://nethackscoreboard.org/) is the NetHack community's leaderboard across servers and variants, and [[Junethack]] is the community's cross-variant tournament, held every June. Both read the game logs of a fixed list of servers, such as the NAO and Hardfought public servers, so a game you play on your own device counts only if the port reports it to one of those servers. These projects on this page have their games counted by both:

- **GnollHack:** Every build except the [[Legacy Windows Version]] can post finished games to the [[GnollHack Account]] server, which both sites track. The NetHack Scoreboard needs [[Classic Mode]] and [[/Difficulties/Expert]] difficulty or higher. For Junethack, link your Junethack username to your GnollHack Account and turn on [[Tournament Mode]]. GnollHack games on the Hardfought servers are counted as well.
- **Hardfought web terminal:** Games on all three Hardfought servers, including the variants with tiles, such as xNetHack, EvilHack, SpliceHack, and UnNetHack.
- **NAO web terminal:** The NetHack Scoreboard counts both NetHack 5.0 and 3.6 games; Junethack 2026 counted only NetHack 5.0.
- **NetHack Tiles Client:** The games run on the NAO and Hardfought servers, so they count the same as games in their web terminals.

The other projects on this page, including NetHack 3D, VoxHack, DartHack, and the official NetHack 5.0 download, keep their games on your own device, and neither site counts them. WebHack and the online mode of nethack.app keep their games on their own servers, with high score lists that the NetHack Scoreboard does not read, and neohack keeps its own public ledger of games, which neither site reads. EvilHack and xNetHack games count only when played on Hardfought, not in their Windows downloads.

## 🏆 Most Developed Interfaces

Counting only the work on the graphical interface itself, not gameplay changes or server hosting, these projects are the furthest along:

- **GnollHack** — Over 23,000 animated tiles, 37 music tracks, over 1,100 sound effects, and over 5,000 voiced lines, in a custom interface built for touch, mouse, keyboard, and game controllers. The interface has been developed since 2019 and runs on Android, iOS, Linux, macOS, Windows, and the Steam Deck.
- **NetHack 3D** — A full 3D renderer with overhead, first-person, and virtual reality views, several built-in tile sets, and sound effects, developed since 2025. It runs in web browsers and on Android, Linux, macOS, Windows, and Meta Quest, and has frequent releases.

## 💡 Which One to Pick?

### Order and Signs

The port lists below are ordered as follows:

1. Projects marked ⭐, which have the most developed interfaces.
2. Other established projects.
3. Experiments.
4. Projects marked 📱, which run on a Mac only as an iPad app.
5. Projects marked ⌨️, which use an on-screen keypad or keyboard on a phone or tablet.
6. Projects marked ⚠️, whose saved games can be lost.

### Additional Signs

- ⚡ marks a project that installs from Steam, Google Play, or the App Store in one click.
- ✅ marks a project that plays the current version of vanilla NetHack, 5.0.
- 🕰️ marks an older version of vanilla NetHack.
- 🌍 marks a browser version with nothing to install.
- 🖥️ marks a browser version that needs a desktop computer (no touch support).
- 🎵 marks a project with both sound effects and music.

A project carries the same signs in every list it appears in, except for the signs that matter only on some devices: 📱 appears only in the Mac list, ⌨️ only in the lists for phones, tablets, and mobile web browsers, and 🖥️ only in the desktop web browser list. Projects are ordered by 📱 and ⌨️ only in the lists that show these signs. In the lists for one version of vanilla NetHack, a project that plays several versions shows only the sign for that version.
