**Last updated:** 12 November 2026

This policy describes the cookies, local storage and tags used on the GnollHack account website, [account.gnollhack.com](https://account.gnollhack.com).

## Optional tags

The account website can use the following tags, but only after you click **Accept** in the cookie notice:

- **Google Tag Manager** — Loads the Google Analytics tag.
- **Google Analytics** — Counts visits and shows how the website is used.

If you click **Decline**, or make no choice, these tags are not loaded. You can change your choice at any time under **Cookie Settings** in the footer of the website. Declining or withdrawing your consent removes the Google Analytics cookies the website can reach.

Google Analytics sets the following cookies after you accept:

- **`_ga`** — A random identifier that distinguishes visitors.
- **`_ga_<container ID>`** — Keeps the state of the current visit.

## Necessary cookies and storage

The website sets the following cookies and local storage entries itself. They are needed for the website to work and are not used for analytics.

| Purpose | Name |
|---------|------|
| **Sign-in** | `.AspNetCore.Identity.Application` |
| **Two-factor sign-in steps** | `Identity.TwoFactorUserId`, `Identity.TwoFactorRememberMe` |
| **Sign-in with an external provider, if one is offered** | `Identity.External` |
| **Form protection (antiforgery)** | `.AspNetCore.Antiforgery.<suffix>` |
| **Temporary messages between pages, including a password reset code until the reset is done** | `.AspNetCore.Mvc.CookieTempDataProvider` |
| **The consent choice, in local storage** | `cookieConsentChoice` |
| **The table layout preference, in local storage** | `rpgTableLayout` |

## No ads

The account website shows no ads.
