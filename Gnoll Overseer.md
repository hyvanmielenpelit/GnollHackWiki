> 👉 **The Gnoll Overseer is a free, optional AI assistant for GnollHack, available in the game and at [overseer.gnollhack.com](https://overseer.gnollhack.com). It answers from the game's own data, the GnollHack and NetHack wikis, and, when you open it during play, your current game.**

## ℹ️ Quick Facts

| Fact | Value |
|---|---|
| **Cost** | Free with the system models; you pay your provider if you use your own API key |
| **Requires** | A [[GnollHack Account]] and an internet connection |
| **Open from** | The in-game menu, the About page, or the web |
| **AI providers** | Anthropic, Google, and OpenAI |
