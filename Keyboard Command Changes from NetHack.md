> 👉 **GnollHack uses mostly the same keys as NetHack. This page lists the commands whose keys have changed, the new commands, and the new keys in item menus.**

## 🧭 Basic Movement

GnollHack uses the same keys as NetHack for movement.

### 🔢 With Number Pad

You can use the number pad for movement.

- **1–4, 6–9**: Movement to a direction
- **5 + Direction**: Run to a direction

### ⌨️ Without Number Pad

If you lack a number pad on your keyboard, you can use the following keys for movement (by default configuration):

- **West**: Left Arrow (or 4)
- **East**: Right Arrow (or 6)
- **North**: Up Arrow (or 8)
- **South**: Down Arrow (or 2)
- **Southwest**: 1
- **Southeast**: 3
- **Northwest**: 7
- **Northeast**: 9
- **Run**: `Shift` + direction, or `5`, `g` or `Shift+g` followed by a direction

## 🔄 Command Keys Changed in GnollHack

- Chat (`Shift+c`)
- Name (`Shift+n`)
- Skills (`Shift+s`)
- Sit (`Ctrl+s`)
- Save (`Alt+s`)
- Take off many (`Alt+t`)

## ✨ New Commands in GnollHack

- Abilities (`Shift+a`)
- Break (`Ctrl+b`)
- Commands menu (`Alt+c`)
- Dig (`Ctrl+g`) (useful in garden rooms for finding roots)
- Character details (`}`)
- Mix spells (`Shift+x`)
- Examine (`Alt+x`)
- View spell (`Alt+z`)
- Spell menu (`+`)
- Yell for pets (`Ctrl+y` / `Alt+y`)

## ⚙️ Command Behaviors Changed in GnollHack

- **Apply wand (`a` + wand)**: Does not break the wand but applies the effect of the wand to an item. Use Break (`Ctrl+b`) to break a wand.

## 🎒 New Item/Inventory Menu Commands

- **7**: Select/unselect all [[art objects]]
- **8**: Select/unselect all [[miscellaneous items]]
- **9**: Select/unselect all [[reagents]]
- **' (apostrophe)**: The same as `$` (use this if you cannot type `$` on your keyboard). Works in the text-based interfaces.
- **# + number**: Number of items to select. Because `7`, `8` and `9` select whole item groups when typed first, press `#` before the number to select, for example, 8 items instead of all miscellaneous items. Works in the text-based interfaces.
